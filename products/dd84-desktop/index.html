Know what is ready

Supported exported-value drafts and CSV review are available. Native HPT/Holley writing, automatic learning and vehicle flashing are not available in this preview.

Each workspace saves its own record. Switching workspaces keeps your current work open; closing the app does not autosave.

1. Open a calibration project

Open synthetic DD84_STUDIO_V2 projects, legacy V1 projects or real exported-value drafts. Native HPT, BIN and Holley containers still require a validated controller/OS adapter; opening a draft does not provide native file editing.

Import real exported parameters

Complete readable Sierra MAF, spark, cooling and VE zone boundary exports can be edited as DD84 drafts. VE coefficients and Holley candidate spark values remain read-only while physical units and scaling are unverified. This does not decode or save native HPT, HEFI or TERX files.

Tables from different tune fingerprints cannot be merged. Missing controller/OS identity stays unverified. Exported originals are table backups, not backups of a complete native tune.

Finish a project in four steps
  1. Open. Start with a DD84 project or supported parameter export. Use the sample to practice.
  2. Edit. Search for a parameter. Change one value or preview a range adjustment. Undo is available; originals stay preserved.
  3. Review. Compare with the original, then explain the purpose of your changes.
  4. Save. Save a project copy, an original-value backup and a review draft as needed. Wait for the Saved confirmation after each dialog.
Files, privacy & recovery
How do I export a VCM Scanner log?
Use VCM Scanner to export the recording as CSV. The supported export starts with “HP Tuners CSV Log File”, Version 1.0, and includes channel IDs, names, units and Offset in seconds. Renaming an HPL file does not convert it.
Where is my work saved?
You choose the folder and filename in each Windows save dialog. Save each workspace separately. Reports store notes and fingerprints, not complete copies of your original HPT/HPL/CSV files. Keep those source files together with your reports.
What happens when I switch workspaces?
Your current files and edits stay open in this session. Switching is not a save. This preview does not provide autosave or crash recovery; save before closing.
Why is a parameter read-only?
Editing requires a known definition with supported units, axes and bounds. Unknown controller definitions and unverified Holley values are preserved but cannot be edited. A file extension alone does not establish compatibility.
Can this app flash my vehicle or learn a tune?
No. Vehicle writes and automatic tuning remain disabled. The device workspace supports the existing USB bench checks and software rehearsal only.
Need help from DD84?
Include Studio version 0.28.0, the workspace, file type and the exact error. Keep customer files private unless you choose to share them.
